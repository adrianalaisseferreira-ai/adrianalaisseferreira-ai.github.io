# Portfólio Adrisses

Instale o Node.js 20 ou superior. No terminal, dentro desta pasta:

```sh
npm install
npm run dev
```

Abra http://localhost:5173. Para encerrar, use Ctrl+C.
Não há dependências externas. O servidor é somente para desenvolvimento local; as alterações aparecem ao atualizar a página.

## GitHub Pages
Envie os arquivos extraídos ao repositório e publique a partir da raiz. Não é necessário build. HTML, CSS, JavaScript e imagens continuam estáticos.
